# Contributions

We welcome contributions to the LOGAN project. To propose a change, add a new feature, or fix a bug:

- Fork this repository.
- Create a new branch for your feature or bug fix.
- Make and test your changes.
- Submit a pull request with a clear and detailed description of the proposed changes.

For bugs that do not require a code contribution, please open an issue to document the problem and help maintain an project official record.
